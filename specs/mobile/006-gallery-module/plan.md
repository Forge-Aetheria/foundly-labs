# Implementation Plan: Mobile Gallery Module

**Branch**: `006-gallery-module` | **Date**: 2026-10-25 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/mobile/006-gallery-module/spec.md`

## Summary

Replace the mobile Galería placeholder with a real gallery backed by the existing GraphQL API. The module lists tenant photos, supports adding photos through the shared image upload helper or a manual URL, shows optional title/description/category, and deletes photos with confirmation.

The API already exposes `gallery`, `addGalleryItem` and `removeGalleryItem`. Editing metadata and reordering are intentionally out of scope because no update/reorder mutations exist.

## Technical Context

**Language/Version**: TypeScript 5.9 strict, React 19.3, React Native 0.88, Expo SDK 58.

**Primary Dependencies**: `@tanstack/react-query`, `graphql-request`, `expo-image-picker`, generated GraphQL types.

**Storage**: Supabase Storage (`tenant-media`) for uploaded images; existing `GalleryPhoto` table; no schema changes.

**Testing**: Jest 30 + `jest-expo` + RNTL. Add pure helper tests for validation/mapping.

**Target Platform**: iOS and Android.

**Project Type**: Mobile app inside the pnpm/Turborepo monorepo.

**Performance Goals**: Gallery visible in under 2 seconds; newly added photo reflected in under 2 seconds.

**Constraints**: Reuse the shared media helper, `LoadingState`, `EmptyState`, `ErrorState`, `Button` and `TextField`; no direct data calls in UI; tokenized colors.

**Scale/Scope**: Tenant gallery; list/add/delete; optional metadata; image fallback handling.

## Risks and Mitigations

| Risk | Mitigation |
| ---- | ---------- |
| Broken or invalid image URLs | Show a fallback card and keep the rest of the gallery usable. |
| Oversized/invalid uploads | Reuse shared media helper validation (format, 5 MB). |
| Duplicate submissions | Disable save/delete controls and show pending state. |
| Stale gallery after mutations | Invalidate `['gallery', tenantId]` on settle. |
| Category drift vs web | Mirror `local`, `trabajos`, `equipo` labels in a local constants file. |
| API lacks edit/reorder | Explicitly out of scope; document in spec and UI copy. |
